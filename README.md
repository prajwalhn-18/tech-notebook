# Tech Notebook 📚

A comprehensive, open-source technical knowledge base covering everything from programming fundamentals to advanced software engineering concepts. Whether you're a complete beginner or an experienced developer, this notebook provides clear, practical guides for mastering technology.

## 🎯 What's Inside

### 🌐 Technology Fundamentals
Deep-dive explorations into how technologies work from the ground up:
- **Email Systems** - Complete understanding of SMTP, POP3, IMAP, delivery mechanisms, and email infrastructure
- **Internet Architecture** - How the internet works: protocols, routing, DNS, physical infrastructure, and networking
- **More coming soon** - HTTP/HTTPS, WebSockets, OAuth, TLS/SSL, and other core technologies

### 💻 Programming Languages

#### C++ Programming (Complete Beginner to Expert)
A comprehensive 12-lesson course designed for absolute beginners:
- **Fundamentals** - Variables, operators, control flow, loops, functions
- **Data Structures** - Arrays, vectors, strings, structures
- **Object-Oriented Programming** - Classes, encapsulation, constructors
- **Memory Management** - Pointers, references, dynamic allocation

Written in simple language with clean code examples, practical exercises, and real-world applications.

#### JavaScript
Advanced JavaScript concepts and patterns:
- Core fundamentals and async programming
- Closures, scope, and the event loop
- Prototypes, inheritance, and `this` binding
- Functional programming patterns
- Memory management

### 🏗️ Software Engineering

#### High-Level Design (HLD)
System architecture, scalability, and design patterns for building robust applications.

#### Low-Level Design (LLD)

#### Design Patterns
Common software design patterns with practical examples and use cases.

### 🗄️ Databases
Database fundamentals, SQL, NoSQL, optimization techniques, and data modeling.

### 🧮 Data Structures & Algorithms (DSA)
Essential data structures and algorithms with explanations and implementations.

### 🔧 Development & Tools
Modern development practices, version control, CI/CD, and developer tools.

### 🚀 Deployment
Deployment strategies, containerization, cloud platforms, and DevOps practices.

### 🧪 Testing
Testing methodologies, unit testing, integration testing, and test-driven development.

### 🤖 AI Agents
Building intelligent agents, understanding AI concepts, and practical implementations.

### 💼 Software Management
Project management, agile methodologies, team collaboration, and software lifecycle.

## 🎓 Learning Philosophy

This notebook follows these principles:

1. **Start Simple** - Concepts explained as if teaching a 13-year-old
2. **Build Progressively** - Each topic builds on previous knowledge
3. **Practical Focus** - Real-world examples and hands-on exercises
4. **No Assumptions** - Assumes no prior knowledge for beginner sections
5. **Deep Understanding** - Goes beyond surface-level to explain the "why"

## 🛠️ Built With

This website is built using [Docusaurus 2](https://docusaurus.io/), a modern static website generator.

### Installation

```bash
yarn
```

### Local Development

```bash
yarn start
```

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.

### Build

```bash
yarn build
```

This command generates static content into the `build` directory and can be served using any static contents hosting service.

### Deployment

Using SSH:
```bash
USE_SSH=true yarn deploy
```

Not using SSH:
```bash
GIT_USER=<Your GitHub username> yarn deploy
```

If you are using GitHub pages for hosting, this command is a convenient way to build the website and push to the `gh-pages` branch.
